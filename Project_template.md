# Задание 1. Анализ и планирование

### 1. Описание функциональности монолитного приложения

Приложение позволяет организовывать удаленное управление отоплением в доме.


**Управление отоплением:**

- Пользователи могут управлять отоплением
- Система поддерживает установку желаемой температуры, включение и выключение системы отопления.

**Мониторинг температуры:**

- Пользователи могут проверять температуру
- Система поддерживает просмотр текущей температуры

### 2. Анализ архитектуры монолитного приложения

Система "Smart Home Monolith" представляет собой монолитное приложение, организованое в соответствии со стандартной структурой Maven проекта.

Все взимодействия с системой происходят в синхронном режиме
- команды изменяющие состояния, синхронно вносят изменения в базу данных
- запросы за данными, синхронно считывают изменения из базы данных

Используемые технологии
- Язык программирования - Java (весрия 17)
- Основной фреймворк - Spring Boot (версия 3)
- Система сборки - Maven (версия >=3.8.1 && <4.0.0)
- База данных - PostgreSQL (версия 15)

### **4. Проблемы монолитного решения**

- Отсутсвует возможность самостоятельного подключения нового дома / устройства со стороны пользователя
  - Подключение новых домов / устройств требует ручной конфигурации системы
  - Подключение новых домов / устройств сопровождается выездом специалиста () 
- Решение опрашивает все подключенные дома / устройства, что может негативно влиять по производительность при увеличении устройств 
- Отсутсвует механизм подключения новых типов устройств
  - Сейчас поддерживается ограниченный функционал умного дома, только устройства отопления
